# 设计说明 · 三国塔防

## 设计取向
对标《Kingdom Rush》《保卫萝卜》的爽点，套三国皮：
- 多塔种 + 升级树（_build 深度）
- 兵种差异化（轻骑快 / 重甲抗 / 攻城车血厚 / BOSS 高威胁）
- 波次递增 + BOSS 武将（节奏张力）
- 主动技能（策略点）
- 星级评价（重玩动力）

## 核心循环
建塔（gold）→ 出战 → 击杀获利 → 升级/补塔 → 撑过 BOSS 波 → 按剩余城池评星 → 解锁下一关。

## 技术约束（沿用仓库惯例）
- 纯静态、零外部依赖，`file://` 双击也能跑（classic script）。
- 多档案 localStorage 存档键：`powerlink3:profiles:v1` / `powerlink3:current:v1`，导出为 JSON 备份。
- 弹层一律用 `[hidden]{display:none!important}`，杜绝透明覆盖吞点击（game/ 历史坑）。

## 平衡基线（config.js，可改）
- 起始金币 230/245/265，城池耐久 20/18/16，血量缩放 1.0/1.35/1.8。
- 塔基础费 70–110；升级费 60–160。击杀奖励 8–130。
- 难度随波次线性增长，BOSS 波在最后一波。
