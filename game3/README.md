# 三国塔防 · 烽火连城（PowerLink3）

纯静态网页塔防小游戏，三国题材，休闲消遣，支持多个人档案与本地存档。
与 `game/`、`game2/` 同源：无构建、无外部 CDN、零素材依赖，整文件夹直接部署到 GitHub Pages 即固定网址。

- **网址**：`https://hxj0515.github.io/csg-power-daily/game3/`
- **技术**：HTML5 Canvas + 原生 JS（classic `<script>`，无 ES module）

## 玩法
- 选「将军」建个人档案，进度自动存于本机浏览器；换设备用「导入存档」备份 JSON。
- 在道路两侧空地建造防御塔，消耗金币；击杀敌军获利；敌人抵达城池扣耐久，归零即败。
- 4 系防御塔，各 3 级：
  - 🏹 弓弩营（蜀）：单体高频，性价比之选
  - 🔥 火攻营（吴）：范围灼烧，克制成群轻骑/步兵
  - 🛡️ 陷阵营（魏）：寒铁减速，控场核心
  - 📜 谋士营（汉）：法术穿甲，重甲克星
- 2 个主动技能（点地图释放，有冷却）：🔥 火烧赤壁（范围爆发）、🌀 八阵图（定身眩晕）。
- 3 场战役：长坂坡 / 赤壁 / 官渡，难度递增、含 BOSS 武将；通关解锁下一关，按剩余城池评 1–3 星。

## 目录
```
game3/
├── index.html      入口（按 config→save→engine→ui 顺序加载）
├── style.css       国风鲜明卡通主题
├── config.js       全部数值：地图/塔/敌/技能/波次生成
├── save.js         多档案存档（localStorage + 导出导入）
├── engine.js       Canvas 渲染 + 模拟（波次/索敌/伤害/技能/胜负）
├── ui.js           屏幕路由 + HUD + 建造/技能交互
└── design/         设计说明
```

## 调参
改 `config.js` 即可：塔的伤害/射程/攻速/升级费、敌人血量/速度/护甲、技能数值、地图路径 `waypoints`（网格坐标）与 `blocked` 装饰格、波次由 `genWaves` 程序化生成。
