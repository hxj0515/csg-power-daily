# 南方电网电力讯息 · csg-power-daily

南方电网电力运行、负荷、绿电、现货与重大工程**每日动态监测**门户（GitHub Pages 静态站）。

- 站点：https://hxj0515.github.io/csg-power-daily/
- 数据：每日 `daily.json` 驱动「每日电力动态」板块；其余栏目聚合自南网官网、南网报、新华网、中国经济网、证券时报等公开渠道。
- 更新：`python update_daily.py "提交说明"` 提交并推送到 `main` 分支，GitHub Pages 自动发布。
- 同源站点：csg-power-daily2（招投标讯息）、csg-power-daily3（组织动态）、csg-power-hub（导航页）。
