# 电亮学堂 · PowerLink2（低压配电网知识闯关）

《电亮学堂》是《电亮全城 PowerLink》的姊妹科普作，面向南方电网一线员工、电力职业院校学生及电力安全爱好者，用「一题一知识点」的闯关方式讲解低压配电网安全知识。

- 展示名：《电亮学堂》（内部代号 PowerLink2）
- 固定网址：`https://hxj0515.github.io/csg-power-daily/game2/`
- 技术形态：**纯静态网页、零构建、零外部依赖**（仅 vanilla HTML/CSS/JS，可双击 `index.html` 在 `file://` 下运行，也可部署到 Pages）

---

## 玩法

1. **建档**：首次进入需创建档案（取名 / 选色 / 选图标）。支持多档案本地存档。
2. **章节闯关**：按知识点分章分关；章节按累计星数门槛解锁，关卡内顺序解锁。
3. **答题**：6 种题型（单选 / 多选 / 判断 / 填空 / 排序 / 连线）。
4. **知识点卡片**：每题提交后底部上滑卡片，讲解本题 `knowledge` 与 `explain`，形成记忆锚点。
5. **星级结算**：按正确率评定（≥90% → 3★，≥70% → 2★，完成即得 1★），记录最佳分与累计错题数。
6. **每日挑战**：按本地日期确定性生成题库，不补做往日（历史灰显）。
7. **设置**：音效（WebAudio 实时合成，无音频文件）、减少动效、导出 / 导入存档、切换 / 编辑 / 删除档案。

### 可访问性
- 键盘：数字键 `1–9` / 字母 `A–Z` 选择选项；`Enter` 提交 / 继续；`Esc` 暂停。
- 所有可点击元素命中区 ≥ 44×44px，焦点环可见；排序/连线均提供非拖拽替代（上下按钮 / 点选连线）。

## 本地运行

**方式一：直接双击**
双击 `game2/index.html` 即可在浏览器打开（`file://` 下可玩）。

> 说明：部分浏览器在 `file://` 下会禁用 `localStorage`，此时游戏自动降级为「内存模式」——进度只在本次会话有效，顶部会提示并高亮「导出存档」。把整个 `game2/` 放到 `http(s)://` 下打开即可启用持久化本地存档。

**方式二：本地静态服务器（推荐自测）**
```bash
# 在 game2/ 目录下任选其一
python -m http.server 8080
# 或
npx serve .
```
然后浏览器访问 `http://localhost:8080/`。

## 如何替换真实题库

题库完全由 **`game2/questions.js`** 一个文件定义（先于 `game.js` 以经典 `<script>` 引入，无 ES module）。把里面的 **示例占位题** 换成真实低压配电网内容即可，无需改动任何引擎代码。

### 顶层结构
```js
window.POWERLINK2_BANK = {
  chapters: [
    {
      id: 'c1',                 // 全局唯一且稳定的章节 id
      title: '安全用具与操作规程',
      icon: '🧤',
      desc: '章节简介',
      levels: [
        {
          id: 'c1-l1',          // 全局唯一，直接作为存档 progress 的 key
          title: '验电与接地',
          questions: [ /* 见下 */ ]
        }
      ]
    }
  ]
};
```

### 6 种题型的字段（schema 唯一依据见 `design/question-spec.md`）

| 题型 | 必填字段 | `answer` 类型 | 说明 |
|---|---|---|---|
| `single` 单选 | `q`, `options[]`, `answer` | `number`（正确项下标，0 起） | `options` 顺序即下标 |
| `multi` 多选 | `q`, `options[]`, `answer` | `number[]`（正确项下标数组） | 判分按**集合相等**，顺序无关 |
| `bool` 判断 | `q`, `answer` | `boolean` | `true`=正确，`false`=错误 |
| `fill` 填空 | `q`（含 `__` 占位）, `answer` | `(string \| string[])[]` | 每空一个元素；数组表示该空可接受的多答案；`__` 数量须等于 `answer.length` |
| `order` 排序 | `q`, `items[]`, `answer` | `number[]` | `items` 为规范顺序，`answer` 是 `0..n-1` 的排列 |
| `match` 连线 | `q`, `pairs[]` | 无（配对由 `pairs` 下标决定） | `pairs[i]={left,right}` 即第 i 对 |

**所有题型都必须有 `explain`（讲解正文）与 `knowledge`（知识点标题）**，二者构成每题后的「知识点卡片」。

### 替换注意事项（易错点）
1. `answer` 类型随 `type` 变化，引擎按 `type` 分支解析，**不要统一当数组**。
2. `fill` 的 `__` 数量必须等于 `answer.length`，且顺序对应；多答案用数组，例：`answer: [['380','380v','380V'], '220']`。
3. `multi` 判分是集合相等（顺序无关）；`options` 顺序改了必须同步改 `answer` 下标。
4. `order.answer` 必须是 `0..n-1` 的排列；游戏会打乱显示，但判定始终按 `items` 下标比对。
5. `match` 配对关系由 `pairs` 数组下标决定；游戏打乱右列，玩家连线后按下标还原比对。
6. `chapter.id` / `level.id` 务必稳定唯一，改名或改 id 会丢失对应进度。
7. 填空答案比较统一 `trim + 忽略大小写/单位`，数字建议直接用字符串，多答案任一匹配即算对。

> 当前 `questions.js` 内含 14 道**示例占位题**（已逐题标注「示例占位，由用户替换为真实题库」），覆盖全部 6 种题型，分布于 2 章节 4 关，仅用于演示结构与交互。上线前请替换为真实题库。

## 存储与降级

- 存档键：`powerlink2:profiles:v1`（档案数组）、`powerlink2:current:v1`（当前档案 id）。
- 多档案：新建 / 切换 / 改名 / 改色 / 改图标 / 删除；导出为 `{ version: 2, ... }` 的 JSON，导入按 `id` 合并（同 id 覆盖、新 id 追加、损坏或 `version≠2` 拒绝）。
- `file://` / 隐私模式 / 容量满：自动降级为内存存储，顶部提示并高亮导出，导入导出仍可用。
