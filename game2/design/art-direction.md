# 视觉方向（game2 / PowerLink2）— 绿能明亮 · 科普插画风

## 0. 定位说明
《电亮全城 PowerLink》（game/）是**深蓝控制室风**：专业、调度、严肃。本作刻意区隔为 **绿能明亮 + 科普插画**，传达「亲切培训 / 安全科普」调性；但仍保留电力联想：⚡/🔌 图标、绿色电网脉络背景、设备插画。展示名建议《电亮学堂》。

## 1. 调色板（hex）
| 角色 | 名称 | hex | 用途 |
|---|---|---|---|
| 主色 | 清新绿 | `#2E9E5B` | 主按钮、进度填充、标题强调 |
| 背景 | 淡绿白 | `#F2FAF4` | 页面底色 |
| 面板 | 云白 | `#FFFFFF` | 卡片/弹窗底 |
| 文字 | 墨绿黑 | `#1F2D27` | 正文/标题 |
| 强调 | 暖橙 | `#FFB02E` | 星级、重要 CTA、奖励 |
| 警示 | 珊瑚红 | `#E5484D` | 错误、安全警示 |
| 信息 | 知蓝 | `#2D7FF9` | 知识卡片链接/提示 |

对比度：文字 `#1F2D27` 对 `#F2FAF4` ≥ 4.5:1（满足 WCAG AA）。

## 2. 字体与字阶
- 字体栈：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`（零外部字体，file:// 与 Pages 通用）。
- 字阶（px）：H1 28 / H2 22 / H3 18 / Body 16 / Caption 13 / 题号 14。
- 行高 1.5；标题字重 700，正文 400。

## 3. 组件风格
- **按钮**：圆角 12px；主按钮绿底白字带轻微阴影；次按钮白底绿边；点击有 1px 下压反馈。
- **卡片**：白底圆角 16px，柔和阴影（`0 4px 16px rgba(0,0,0,.06)`），左上角插画角标。
- **弹窗（知识点卡片）**：底部上滑 sheet，顶部 4px 绿边，含 `knowledge` 标题 + `explain` 正文 + 「继续」按钮。
- **进度条**：圆角胶囊，绿填充，星标节点显示关卡星数。
- **题目卡片**：顶部插画 icon + 题干 + 选项网格（A/B/C 字母标签，命中区 ≥44px）。

## 4. 图标（零外部文件）
- 用 emoji 或内联 SVG token（不引外部资源，避免 CDN/依赖）。
- 设备类：🔌 插座/接线、⚡ 电能、🔧 工具、🛢️ 变压器
- 安全类：🧤 绝缘手套、🪫 验电、🛡️ 保护、⚠️ 警示
- 知识类：📘 知识点、✅ 正确、❌ 错误、⭐ 星级
- 档案图标：从限定 emoji 集选择（避免缺字平台差异）。

## 5. 动效
- 卡片淡入上滑 200ms；星星弹出弹簧；正确绿色脉冲；错误红色抖动。
- 全部动效在 `reduceMotion = true` 时降级为瞬时（无过渡），对应 `settings.reduceMotion`。

## 6. 音效方向（WebAudio 合成，零文件）
- 正确：上行三音 ding（正弦，短）。
- 错误：低频 buzz（方波，短）。
- 星级：琶音（3–5 音）。
- 点击：轻 tick。
- 关卡完成：小和弦。
- 全部由 `AudioContext` 实时合成，`settings.sound` 控制开关；无音频文件、无外部请求。
