# 《电亮学堂》游戏概念文档（game2 / PowerLink2 低压配电网闯关）

> 内部代号 **PowerLink2**，展示名以本文「命名建议」为准。本作是《电亮全城 PowerLink》（game/）的姊妹科普作，但视觉与定位完全不同（见 art-direction.md）。固定网址 `https://hxj0515.github.io/csg-power-daily/game2/`。

## 1. 命名建议（供选）
1. **《电亮学堂》**（主推）——「电亮」呼应电力科普，「学堂」点题培训教室风，亲切零门槛。
2. **《配网小卫士》**——以「安全守护」视角强化低压安全用具/操作规程主题，可爱护盾感。
3. **《低压闯关记》**——直白点题「低压配电网 + 闯关」，对一线员工检索友好。

展示名与 localStorage 命名空间 `powerlink2:` 解耦：命名空间固定为工程标识，展示名可随时替换。

## 2. 设计支柱（3 条）
- **P1 寓教于乐、零门槛**：把低压配电知识拆成「一题一知识点」，用游戏化讲解替代考试压力。
- **P2 每次一题一卡片**：每题后弹「知识点卡片」（explain + knowledge），形成记忆锚点，碎片化可学。
- **P3 安全优先**：所有内容以「安全用电 / 规范操作」为正向底色，答错也引导回规范。

## 3. MDA 框架
- **Mechanics（机制）**：6 种题型答题；知识点卡片弹窗；关卡内穿插排序/连线轻互动；星级评分；按累计星数解锁章节；每日挑战；多档案本地存档；设置（音效 / 减少动效）。
- **Dynamics（动态）**：为集星反复刷题；卡片讲解沉淀知识；每日挑战驱动日活回访；自选档案名/色/图标带来归属感。
- **Aesthetics（美学）**：发现（知识点卡片）、挑战（星级）、表达（自定义档案）、关怀（安全用电价值观）。

## 4. 目标人群
- 南方电网一线员工 / 新员工入职培训
- 电力职业院校学生
- 对安全用电感兴趣的普通用户

## 5. 核心循环
建档 → 选章节/关卡 → 答题（每题后知识点卡片）→ 关卡结算（星级 + 得分）→ 累计星数解锁下一关 → 每日挑战回访

## 6. 范围分层
### MVP（首版可上线）
- 4 题型：单选 / 多选 / 判断 / 填空
- 知识点卡片、章节/关卡选择、单档案、星级、localStorage 存档
- 每日挑战（简单版，固定抽题）

### 完整版（后续迭代）
- 6 题型：新增排序 / 连线
- 多档案、导出/导入、设置（音效 / 减少动效）、可访问性（文字 + 图标辅助）
- 动效与 WebAudio 合成音效、每日挑战轮换题库

## 7. 进度与积分/星级系统草案
- **关卡得分**：每题基础分 100，答错不加分（仅影响星级）；`bestScore` 取历史最高分。
- **星级规则**（按正确率）：
  - 3★：正确率 ≥ 90% 且完成
  - 2★：正确率 ≥ 70%
  - 1★：完成即获得
- **解锁规则**：
  - 关卡内顺序解锁：第 N 关需第 N-1 关 `completed = true`（≥1★）
  - 章节解锁：累计星数门槛（见下表，可调）
- **累计星数门槛表（建议）**：

  | 解锁章节 | 需累计星数 |
  |---|---|
  | Ch2 | 9 |
  | Ch3 | 18 |
  | Ch4 | 30 |
  | Ch5 | 45 |
  | Ch6（综合 / 每日） | 60 |

## 8. 章节(Chapter) → 关卡(Level) 结构建议

| 章节 | 主题 | 关卡数 | 知识点覆盖 |
|---|---|---|---|
| Ch1 | 安全用具与操作规程 | 4 | 验电 / 接地线 / 标示牌 / 安全用具分类 |
| Ch2 | 变压器与开关设备 | 4 | 配电变压器 / 隔离开关 / 断路器 / 熔断器 |
| Ch3 | 接线、相序与标识 | 4 | 三相四线制 / 相序 / 色标 / 中性线 |
| Ch4 | 保护装置（漏保/过流） | 4 | 剩余电流 / 过流 / 接地故障保护 |
| Ch5 | 规程标准与作业 | 4 | 安全距离 / 安全电压 / 作业监护 |
| Ch6 | 综合实战（每日挑战题库） | 1+ | 跨主题混合 |

- 每关问题数建议 8–12 题（MVP 可先 6 题）。
- `levelId` 稳定且全局唯一（如 `c1-l1`），直接作为存档 `progress` 的 key。
- 题库 schema 见 `question-spec.md`；交互与存档见 `ux-save-spec.md`；视觉见 `art-direction.md`。
